# FlixNova 🎬

**FlixNova** is an ML-powered movie streaming and discovery platform featuring an intelligent recommendation engine, real-time sentiment analysis, and an interactive analytics dashboard.

---

## 🛠️ Tech Stack & Technologies Used

### 🟨 Frontend
* **HTML5:** Core page structure and layouts.
* **CSS3:** Custom styling, dark theme design, responsive components, and keyframe animations.
* **JavaScript (ES6+):** Dynamic UI interactivity, tab switching, star rating system, and search filtering.
* **Chart.js:** Interactive analytics charts for viewing insights and movie statistics.

### 🟦 Backend & Machine Learning (Python)
* **pandas:** Data wrangling, cleaning, and exploratory data analysis (EDA).
* **scikit-learn:** TF-IDF Vectorization and Cosine Similarity for building the ML Movie Recommendation Engine.
* **TextBlob:** Natural Language Processing (NLP) for real-time sentiment analysis on audience reviews.
* **matplotlib:** Data visualization and generating backend metrics charts.
* **NumPy:** High-performance numerical computations.
