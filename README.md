# FlixNova 🎬

A full-stack movie streaming & analytics platform built with 
Python and JavaScript.

## Features
- 🤖 ML Recommendation Engine (TF-IDF + Cosine Similarity)
- 💬 NLP Sentiment Analysis (VADER-style polarity scoring)
- 📊 Live Analytics Dashboard (5 interactive charts)
- 🎬 40+ Movies (Bollywood + Hollywood)
- 🔗 REST API Integration (OMDb API)

## Tech Stack
| Frontend | Backend/ML |
|----------|------------|
| HTML, CSS, JavaScript | Python |
| Chart.js | pandas, numpy |
| REST API | scikit-learn |
| | TextBlob, matplotlib |
